\section{For Loop Syntax}
AutoPDF supports Go template range syntax:

\begin{verbatim}
% Range over arrays
delim[[`delim[[range .tags]]`]]
delim[[`delim[[.]]\par`]]
delim[[`delim[[end]]`]]

% Range over objects with properties
delim[[`delim[[range .features]]`]]
delim[[`delim[[.name]]: delim[[.description]]`]]
delim[[`delim[[end]]`]]
\end{verbatim}

\section{Best Practices}
\begin{itemize}
\item Read every variable from the root, e.g. \texttt{.title} or \texttt{.settings.theme}
\item Range directly over root arrays, e.g. \texttt{range .tags}
\item Test templates with different data structures
\end{itemize}
